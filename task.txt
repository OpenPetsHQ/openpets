0. What this is
---------------

One official plugin: Anxiety Aid Tools.

It is the OpenPets companion of the existing AAT product, not a bag of
unrelated "health" timers and not a fork of the website. Install once.
Pet command opens it. Inside: the practices, with a serious visual
session and the same depth of explanation AAT already has.

First practice we actually build: breathing (simple 4:6 + guided
patterns + custom patterns). English only. We will go back and forth on
this one until it feels right. Then we document what we built. Then we
add PMR and the rest into the same plugin.

It is not therapy. It is not the AAT dashboard, journal, worksheets,
self-tests, sound library, or fidget toys. Those stay on the website.
The plugin mentions and points at https://anxietyaidtools.com/ for the
full web product.


1. Correction from the last draft
---------------------------------

The previous draft was too cheap in the places that matter and too
split in the places that don't.

Wrong:
- Several tiny plugins (breathing / pmr / grounding as separate
  catalog items). That duplicates session chrome and kills the brand.
- Practice as pet speech + a 2x2 HUD. That cannot carry visual phase,
  step state, or the AAT information layer.
- Learn as a stack of bubbles. That cannot hold how-it-works, science,
  when/what, tips, and real references.
- Write docs/calm-pack.md before any breathing UI exists.

Right:
- One plugin, AAT-branded.
- A real session surface with visual indicators, step indicators, and
  an Info control.
- Info opens the AAT knowledge layer properly (on demand, not a lecture
  before the first breath).
- Build breathing in English, tune it on the real app, then document,
  then the other techniques.


2. Why one plugin
-----------------

AAT is already one product. The shared things are the product:

- session window chrome (visual, steps, pause/resume/stop, Info)
- disclaimer, attribution, link to the site
- last-used technique, custom breath patterns, completion stats
- one catalog card, one install, one pet-menu home

Splitting techniques into separate official plugins would mean three
copies of that chrome and no single place to put "Anxiety Aid Tools"
plus the site link.

"Small appliances beat giant knobs" still applies inside the plugin:
it is a practice companion, not a wellness OS. No journal. No tests.
No settings kitchen sink. One job — run a calm practice well.

Do not duplicate existing OpenPets plugins:

- mood-check-in, water-reminder, day-routine, focus-buddy stay theirs
- fidget / stress-ball / bubbles / path-tracing stay on the website
  (pointer toys, not this surface)
- relaxing sounds + guided meditation: REVERSED 2026-09-22 — they
  come into the plugin later (images ship in the plugin, audio streams
  from r2.anxietyaidtools.com); rights + Pro questions still open (§10)


3. The experience bar (deep, not cheap)
---------------------------------------

This is the actual product requirement. If breathing ships without
these, it is not done.

Visual indicators
  The user must see the breath. Expanding/contracting visual tied to
  the real phase clock (AAT orb / circle language, rewritten for this
  window — not a CSS toy that ignores the timer). Phase color/label
  matches in / hold / out. Motion follows the current pattern's
  durations, including custom.

Step indicators
  Always obvious: which pattern, which phase, phase remaining, cycle
  n of N (or elapsed if until-stopped). Steps are a visible track,
  not fine print. During PMR later: muscle group n of N, tense vs
  release. The user should not have to listen to know where they are.

Info button
  A persistent control on the session surface. Opens the AAT
  information for the current technique, presented well:

  - How it works
  - The science, with real citations
  - When to practice / what you'll notice
  - Tips
  - Clinical disclaimer
  - Link/mention of https://anxietyaidtools.com/

  Info is on demand. It must not block Start. It must be readable,
  structured, and specific to the selected pattern (box vs 4-7-8 vs
  default 4:6 are not the same paragraph).

Start in one click
  Last-used pattern, or Calm 4-6 on first run. Pattern picker is
  there, but a stressed person does not hunt.

The pet
  Right-click lists the seven practices under the Anxiety Aid Tools
  submenu. No Pause / Resume / Stop items: session controls live on
  the card only. The pet is not a replacement for the visual. Closing the
  overlay stops honestly; it does not leave a ghost session.


4. Surface: the session happens around the pet (no dedicated window)
--------------------------------------------------------------------

REVERSED 2026-09-21: no panel window. The practice renders around the
pet itself, the way the Pet Assistant chat does — the default pet
window is a carrier that expands in place (anchor-preserving) into an
"expanded-session" state. Current layout (2026-09-22): one HUD card at
the top, the night-sky orb wrapping the pet near its resting spot
below it (the pet rises ~50px), and a separate Info window. The
carrier height is the overlay's own measurement of card + orb.

Mechanism (built):

- New first-class SDK surface `ctx.ui.session` with permission
  `ui:session`. The plugin sends a declarative descriptor: patterns
  (phases with seconds, cycles), selected pattern, autoStart, and the
  Info content (sections, citations, disclaimer, site link — https
  only). Descriptor-only, like bubbles: no plugin markup ever enters
  the pet window.
- Descriptor kinds: "breathing" (patterns, optional per-pattern cues),
  "pmr" (tense/release steps with pose SVGs and cue lists), and
  "grounding" (self-paced senses with items). Practices list with
  icons drives the header practice picker.
- The host owns rendering and the 60fps phase clock (WebGL orb in the
  pet preload). The plugin receives lifecycle events: started, paused,
  resumed, patternChanged, completed, stopped(reason), infoOpened,
  audioToggled, practiceSelected. One session overlay at a time;
  opening another replaces it.
- Coordinator: apps/desktop/src/pet-session-overlay.ts. Descriptor
  validation: apps/desktop/src/plugin-session-descriptor.ts. Renderer:
  apps/desktop/pet-session/ (session-overlay-view.cjs shell +
  breathing/pmr/grounding practice views + orb-renderer.cjs). Icons:
  src/session-icons.ts. Carrier state + geometry: default-pet-chat.ts /
  default-pet-chat-geometry.ts (estimates size the first frame; the
  renderer then reports the exact height). The pet window is pinned
  to 1x zoom.
- Info links (citations, anxietyaidtools.com) open via shell from the
  host, allowlisted to URLs in the validated descriptor — real links,
  no dead buttons.
- Info content ships in the plugin, not fetched from the live site.

Session engine ownership: the host animates the declarative schedule;
the plugin owns patterns, knowledge content, and last-used state.
Sleep/restart reconciliation and programmatic pause/resume/stop from
the pet menu are still open (see log).


5. Breathing (the first thing we build)
---------------------------------------

English copy, translated in the seven host locales. Simple
breathing (Calm 4-6) is the tuned baseline; guided breathing is its
own practice with a pattern picker. Custom patterns are not started.

Patterns (as built):

| practice | id         | name        | phases              | rounds | audio            |
|----------|------------|-------------|---------------------|--------|------------------|
| simple   | calm       | Calm 4-6    | in 4, out 6         | 10     | breath-in/out    |
| guided   | box        | Box         | 4-4-4-4             | 8      | AAT 4-4-4-4 pair |
| guided   | calming    | Calming     | in 4, hold 7, out 8 | 4      | AAT 4-7-8 pair   |
| guided   | energizing | Energizing  | in 4, hold 4, out 6 | 8      | AAT 4-4-6 pair   |
| guided   | quick      | Quick reset | 3-3-3               | 6      | AAT 3-3-3 pair   |
| later    | custom:*   | user-named  | in/hold/out/hold    | —      | —                |

Custom: 1–20s per phase, 0s hold allowed, capped count, unique names,
edited in the panel (form, not a textarea of JSON).

Session states: idle → active → paused → complete.
No pre-session lecture. First run can show a one-line disclaimer in
Info and a small first-run note, then get out of the way.

The host overlay owns the clock (not ctx.schedule); sleep/restart
reconciliation is still open. Pause / Resume / Stop are on the card.

Info for breathing ships the AAT knowledge, rewritten for this UI,
pattern-aware where it matters, with real PMC/journal citations.

Audio cues: short, optional, respect global sound toggle and quiet
hours. Tune after the visual is right; do not block on them.


6. Plugin shape
---------------

Id (proposed): openpets.anxiety-aid-tools
Name: Anxiety Aid Tools
Description: mention practices + official site URL.
Lane: plugins/official/, catalog-listed, not bundled, not enabled
by default.

Commands (as built): one per practice, titled with the practice name
— start-breathing, start-guided-breathing, start-pmr,
start-grounding, start-meditation, start-visualization, start-sounds,
in the plugin's pet-menu submenu. Patterns never go in the pet menu;
they live on the card.

Storage (as built): audioCues (mute toggle), lastGuidedPattern.
Later maybe: customPatterns, stats.

Permissions (as built): ui:session, commands, storage.

Assistant later, not in the breathing tuning loop: start/pause/stop,
list patterns, explain technique.

Practices: built — simple breathing, guided breathing, PMR,
grounding 5-4-3-2-1. Next, in order — peaceful visualization, guided
meditation, relaxing sounds. Staying on the website — thought
labeling, fidget toys, self-tests, worksheets.

License: AAT site is GPL, OpenPets is MIT. Rewrite copy and visuals
for this plugin. Do not copy AAT Vue/i18n/source into this repo.
Citations and protocols you authored are fine as original OpenPets
content. Attribution + site URL are required.


7. Quality bar
--------------

Fails if:
- countdown with "in"/"out" text and no real visual
- no step track
- Info is missing, generic, or a dump of unformatted paragraphs
- citations are fake or unlinked-unidentified
- it claims to treat anxiety or medical conditions
- Info blocks the first breath
- custom patterns are JSON
- the panel is a cropped AAT webpage, including site nav
- mood/journal/sounds/fidget sneak in
- copy sounds like a meditation ad
- docs are written instead of the breathing UI

Passes if:
- you can see the breath and know the step without reading a paragraph
- Info is something you'd actually open, as good as AAT's sections
- Start is immediate; Pause/Stop never stick
- sleep/restart does not leave a ghost session
- the site is credited
- Alvin can sit on breathing and nitpick visuals/copy before we
  touch PMR or docs

   host session machine + panel visual + step track + Info +

4. After breathing is signed off: write the durable docs
   (official-plugins row, plugin contract, codemap). Document what
   we actually built, not the guess in this file.
5. Then PMR in the same plugin, reusing the session chrome.  [done]
6. Then grounding, etc.  [grounding + guided breathing done; next:
   peaceful visualization → guided meditation → relaxing sounds]

No "visual later". No Info-as-TODO. Breathing without those is not
a first slice.
